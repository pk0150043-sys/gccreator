Ultra high-speed, 3D Glassmorphic Web Panel & Automated CLI tool for creating Instagram Direct Group Chats concurrently with multi-user authentication, saved session managers, and real-time live terminal streaming.

---

## ⚡ Features

- **🌐 3D Glassmorphic Web Engine:** High-performance responsive web dashboard for Phone (Android/iOS) and PC (Windows/Mac/Linux).
- **🔑 Role-Based Multi-User Authentication:**
  - **Owner Dashboard:** Multi-User Live Monitor (with Force Stop) & User Management Center (Add/Edit/Delete users).
  - **Standard Users:** Personal GC Creation jobs & saved sessions manager.
- **📁 Instagram Session Manager:** Save, select, and manage multiple Instagram account session IDs.
- **🚀 Real-Time Live Streaming Console:** Real-time WebSocket terminal logs with color codes, live progress bar, and thread ID tracker.
- **🤖 Background Playwright Automation:** Automated search, multi-member selection, initial activation message sending, and custom group naming.

## 🚀 Installation & Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/pk0150043-sys/gccreator.git
cd gccreator
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
playwright install chromium
```

### 3. Run the Web Application
```bash
python server.py
```
Open **[http://localhost:8080](http://localhost:8080)** in your browser.

### 4. Run CLI Mode (Terminal only)
```bash
python gc_creator.py
```
